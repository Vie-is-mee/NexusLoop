# Note

Thư mục này là concept React gốc có phong cách UI mà NexusLoop Ultimate kế thừa. Bản chạy chính hiện nằm trong `../static/` và được FastAPI serve trực tiếp tại `http://localhost:8000` để demo một tiến trình, tránh lỗi CORS/localhost và không phụ thuộc Node khi trình diễn.

Không cần chạy `npm run dev` để sử dụng NexusLoop Ultimate.
