# Research foundation and positioning

NexusLoop does **not** claim to be the first industrial-symbiosis platform.

The project is intentionally built on lessons from existing systems and research:

- **UNIDO Eco-Industrial Parks** — industrial-symbiosis and EIP implementation frameworks in Vietnam.
- **SYNERGie / International Synergies** — opportunity discovery and resource matching.
- **SHAREBOX (EU CORDIS)** — shared process-resource management, optimization, contracts, and regulatory constraints.
- **FISSAC** — feasibility, lifecycle, cost, and material-flow assessment.
- **DigitalH4C** — recent research architecture spanning identification, assessment, implementation, and monitoring.
- **AI permitting / compliance tools** — document extraction and task workflows.

NexusLoop's prototype focuses on a narrower frontier:

> **decision-directed evidence acquisition** — deciding what evidence should be obtained next, and automatically replanning the implementation path when that evidence changes technical, legal, or economic dependencies.
